DARSHAN GATE + COLLEGE STUDY PLANNER

FILES
- index.html: website structure
- style.css: design and responsive layout
- app.js: timetable, checkboxes, progress, task editing and local saving

HOW TO OPEN
1. Extract Darshan_Gate_Study_Planner.zip.
2. Open the Darshan_Gate_Study_Planner folder in VS Code.
3. Double-click index.html, or right-click it and choose Open with Chrome.
4. No installation, Node.js, or internet connection is required for the planner features.

FEATURES
- Monday to Sunday timetable based on the schedule supplied.
- Weekly college subject allocation: CC, PGPUC, DL, CNS, AISSD, labs, Mini Project and ATAR.
- Tick off tasks and view daily / weekly completion percentages.
- Add or delete timetable tasks.
- Weekly reflection notes.
- Saves progress and notes in this browser on this device using local storage.

NOTE
The website starts with the supplied timetable. Changes and completion ticks are saved in the browser where you use the website. Clearing browser data may remove saved progress.

PDF EXPORT
Click "Download Progress PDF" in the weekly timetable section. In the print dialog, choose "Save as PDF" and save the report. The report includes all seven days, completion status, daily percentages, weekly percentage, subject allocation, and reflection notes.
